# 🗂️ Nexus Native File Manager Guide

**Nexus Explorer** is Cortex Workstation's high-performance native Windows file manager, designed to overcome Windows Explorer's limitations when navigating directories with hundreds of thousands of files.

---

## ⚡ Key Capabilities

* **Multi-Tabbed Dual-Pane Workflow:** Open multiple filesystem locations simultaneously with instant split-screen comparison.
* **Hardware-Accelerated VFS:** Streams directory entries asynchronously with zero UI freezing.
* **USN Journal Change Tracking:** Real-time NTFS Update Sequence Number (USN) monitoring for instant file discovery without disk scanning.
* **PAR2 Error Correction:** Built-in Reed-Solomon data verification and bit-rot recovery for critical archives.
* **Infinite Undo/Redo Ledger:** Full transactional history of moves, renames, copies, and folder creations.

---

## ⌨️ Essential Keyboard Shortcuts

| Shortcut | Action |
| :--- | :--- |
| `Ctrl + T` | Open a new filesystem tab |
| `Ctrl + W` | Close the active tab |
| `Ctrl + Z` | Undo last file operation (rename, move, create) |
| `Ctrl + Y` | Redo undone file operation |
| `F2` | Quick rename selected item |
| `F5` | Refresh current directory |
| `Ctrl + F` | Filter current directory items |
| `Alt + Enter` | View forensic file properties & metadata |
