# 🎨 Cortex Workstation Icon Architecture

This directory houses the standalone vector icon assets utilized across Cortex Workstation and Nexus Explorer:

## 📁 Directory Structure

- **`ui/`** (145 icons): High-contrast, theme-tinted vector SVG icons designed for the 132 interactive GUI tool pages, sidebar navigation, window chrome, and status badges.
- **`filetypes/`** (893 icons): Material Design file extension, MIME type, and specialized folder vector icons utilized by Nexus Explorer VFS.
- **`cortex.ico`**: Multi-resolution Windows PE application and setup installer icon (256×256 down to 16×16).
- **`cortex.png`**: High-resolution 256×256 master brand mark.
